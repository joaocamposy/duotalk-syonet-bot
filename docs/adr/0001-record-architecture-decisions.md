# 1. Record Architecture Decisions (ADR)

Date: 2026-08-11

## Status
Accepted

## Context
We need a clear structure to document technical architectural decisions made during the evolution of the Duotalk -> Syonet integration crawler.

## Decision
We will use Architecture Decision Records (ADRs) stored in `docs/adr/` using standard Markdown format.

## Consequences
- Future developers and AI agents can understand the rationale behind architectural choices without guessing.
